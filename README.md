# TurboFPS

Minecraft 26.2 için Fabric tabanlı, istemci tarafında hafif FPS optimizasyon modu.

## Özellikler

- Bulutları kapatır.
- Parçacık miktarını azaltır.
- Sunucuya veya oyun dünyasına müdahale etmez.
- Sadece istemci tarafında çalışır.

## Derleme

Java 25 ve Gradle ile:

```text
gradle build
```

Oluşan mod:

```text
build/libs/TurboFPS-1.0.0.jar
```
